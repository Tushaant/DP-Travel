# DP Travel Solutions

Website for DP Travel Solutions (Estd. 2004): visa services, document attestation and travel plans.

## Run
Static site. Open `index.html`, or deploy the folder to GitHub Pages / Netlify / Vercel.

## Edit business details
Open `index.html` and change the `CFG` object near the bottom (WhatsApp number, phone, email, address, hours).
Destination stamps are in the `D` array just below it.
